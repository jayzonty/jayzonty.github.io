Hamiltonian Escape

Traverse all cells to escape the level

A simple puzzle game where the player needs to visit all cells in a grid to proceed to the next level.

This game was made in 1 week, and was submitted to the Jame Gam #15 (2022) game jam on itch.io with the theme “No Going Back”.

The game was made using C++ and Raylib library, and the music was made using PixiTracker.

Ignis

Game programming library inspired by Raylib

This project was a personal attempt at making a small game programming library inspired by Raylib using C and Vulkan.

The library supports functionalities such as window creation, drawing of simple shapes, random number generation utilities, basic 2D vector math functions, basic font rendering, and Bezier curves.

C Vulkan GLFW
GitHub Repo

Process Scheduling

A game about computer process scheduling

A game that simulates the way operating systems schedule the execution of processes running in a computer. Players need to assign processes to CPU cores, and move them as necessary when they request for I/O processing.

This game was made in 2 weeks, and was submitted to the Finally Finish Something 2021 game jam on itch.io.

The game was made using the Unity game engine.

Unity C#
Play in Browser (itch.io)

Memory Management

A game about allocating memory to computer processes

A game that simulates how operating systems allocate memory to processes running in a computer. Players need to decide which processes to allocate to the RAM at a given time, given their memory requirements and processing time.

This was my first time ever joining a game jam. The game was made in 2 weeks, and was submitted to the My First Game Jam: Winter 2018 game jam in itch.io.

The game was made using the Unity game engine.

Unity C#
Play in Browser (itch.io)
