Hamiltonian Escape

全てのマスを通過して脱出するパズルゲーム

グリッド上のすべてのセルを1度ずつ通過して次のレベルを目指すシンプルなパズルゲームです。

開発期間は1週間で、itch.io のゲームジャム「Jame Gam #15 (2022)」（テーマ：「No Going Back（後戻り禁止）」）に提出されました。

C++とRaylibライブラリを使用して制作され、BGMはPixiTrackerで作成しました。

C++ Raylib

Ignis

Raylibに着想を得たゲームプログラミングライブラリ

C言語とVulkanを使用して、Raylibに着想を得た軽量なゲームプログラミングライブラリを作成する個人プロジェクトです。

ウィンドウ生成、基本図形の描画、乱数生成ユーティリティ、2Dベクトル演算、基本的なフォント描画、ベジェ曲線描画などの機能を備えています。

C Vulkan GLFW

Process Scheduling

OSのプロセススケジューリングを題材にしたゲーム

OSがPC上で実行されるプロセスをスケジュールする仕組みをシミュレーションしたゲームです。 プレイヤーはプロセスをCPUコアに割り当て、I/O処理要求が発生した際には必要に応じて移動させます。

開発期間は2週間で、itch.io のゲームジャム「Finally Finish Something 2021」に提出されました。

Unityゲームエンジンを使用して制作しました。

Unity C#

Memory Management

プロセスへのメモリ割り当てを題材にしたゲーム

OSがPC上で実行されるプロセスにメモリを割り当てる仕組みをシミュレーションしたゲームです。 プレイヤーは各プロセスのメモリ要件と処理時間に応じて、どのプロセスをRAMに割り当てるかを判断します。

初めて参加したゲームジャム作品で、2週間で制作し、itch.io の「My First Game Jam: Winter 2018」に提出しました。

Unityゲームエンジンを使用して制作しました。
