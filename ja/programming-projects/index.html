Simple Video Player

C言語、SDL、FFmpegで作成したシンプルな動画プレーヤー

SDL3とFFmpeg APIの学習のために作成した基本的な動画プレーヤーです。

UIおよびキーボードショートカットによる再生/一時停止、シーク、音量調整機能、ドラッグ＆ドロップによる動画ファイルの読み込みに対応しています。

C SDL ffmpeg

QOI Image Tools

QOI画像ファイル用のC言語エンコーダ/デコーダ

QOI（.qoi）画像ファイルのエンコードおよびデコードを行うシングルファイルCヘッダーライブラリの個人制作プロジェクトです。 また、C++とOpenGLを使用したQOI画像のシンプルなビューアーも含まれています。

ReducibleのYouTube動画「How PNG Works: Compromising Speed for Quality」に触発されて制作しました。

C C++ OpenGL GLFW

Vulkan Model Viewer

シンプルな3Dモデルビューアー

VulkanグラフィックスAPIの学習成果を実践するために制作したシンプルな3Dモデルビューアーです。

C++とVulkanを使用し、3Dモデルの読み込みにはAssimpライブラリを使用しています。

ドラッグ＆ドロップによる3Dモデルの読み込みに対応しており、マウスとキーボード操作でカメラを自由に移動・回転できます。

C++ Vulkan GLFW Assimp
GitHubリポジトリ

Map Viewer 3D

OpenStreetMapの建物・道路データを3D描画

OpenStreetMapの建物および道路のXMLデータを活用し、3D空間上にレンダリングするプロジェクトです。

C++とVulkanを使用し、XMLファイルの解析にはtinyxmlライブラリを採用しています。

リソースフォルダからOpenStreetMap（.osm）ファイルを読み込み、マウスとキーボード操作で3Dマップ内を探索できます。

C++ Vulkan GLFW
