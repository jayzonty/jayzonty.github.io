Simple Video Player

A simple video player made with C, SDL, and FFmpeg

This project was my attempt at creating a basic video player in order to learn SDL3 and the FFmpeg API.

The video player features the ability to play/pause, seek, and adjust volume controls via the UI and the keyboard keys, and also loading of the video file to play via drag-and-drop.

QOI Image Tools

C encoder/decoder for QOI image files

This project was a personal attempt to create a single file C header for encoding and decoding a QOI (.qoi) image file. The project also contains a basic viewer for QOI images made using C++ and OpenGL.

The project was inspired by Reducible’s YouTube video entitled How PNG Works: Compromising Speed for Quality.

C C++ OpenGL GLFW
GitHub Repo

Vulkan Model Viewer

A simple 3D model viewer

This project was an attempt to create a simple 3D model viewer in order to apply what I learned when I was studying the Vulkan Graphics API.

The application was made using C++ and Vulkan, and the Assimp library was used for loading 3D models.

3D models can be loaded via drag-and-drop, and mouse + keyboard controls can be used to control the camera.

C++ Vulkan GLFW Assimp
GitHub Repo

Map Viewer 3D

Rendering OpenStreetMap buildings/roads in 3D

This project was about utilizing the building and road XML data from OpenStreetMap, and rendering them in 3D.

The application was made using C++ and Vulkan, with the tinyxml library utilized for reading XML files.

The application loads OpenStreetMap (.osm) files from the resources folder, and mouse + keyboard controls can be used to navigate through the rendered 3D map.

C++ Vulkan GLFW
